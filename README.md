# AWS CodeConnections .github Repository

This repository stores the GitHub community health and contribution metadata for the AWS CodeConnections organization.

## Included files

- `CODE_OF_CONDUCT.md` — the project code of conduct
- `CONTRIBUTING.md` — contribution guidance for contributors
- `PULL_REQUEST_TEMPLATE` — default pull request checklist
- `SECURITY.md` — security reporting instructions
- `ISSUE_TEMPLATE/bug_report.md` — template for reporting bugs
- `ISSUE_TEMPLATE/feature_request.md` — template for proposing enhancements

## Purpose

This repository is not the application source code itself. It exists to provide the standard GitHub configuration used across the project, including:

- contribution guidelines
- code of conduct
- security disclosure guidance
- issue and pull request templates

For source code, please refer to the project repository that uses this organization-level configuration.
